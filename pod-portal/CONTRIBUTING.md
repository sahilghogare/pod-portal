# Contributing

1. Pick or create an issue (use the issue templates).
2. Create a branch from `develop` using the naming rules in [docs/BRANCH_POLICY.md](docs/BRANCH_POLICY.md).
3. Commit small, focused changes with a message in the form `type: short summary`
   (types: feat, fix, docs, test, build, ci, chore, refactor).
4. Push the branch and open a pull request into `develop`. Fill in the pull request template.
5. Review the changes, make sure the build and tests pass, then merge.

Never commit directly to `main` or `develop`.
